# 🍽️ Zomato Data Analysis Dashboard – Power BI

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant and order data using Microsoft Power BI. The dashboard provides meaningful business insights into restaurant performance, customer orders, revenue, ratings, and city-wise sales.

## 🎯 Project Objectives
- Analyze total orders and revenue.
- Identify top-performing restaurants.
- Analyze city-wise restaurant and order distribution.
- Understand customer ordering patterns.
- Evaluate restaurant ratings.
- Generate actionable business insights.

## 🛠️ Tools & Technologies Used
- Microsoft Power BI
- Power Query Editor
- DAX (Data Analysis Expressions)
- Microsoft Excel
- SQL
